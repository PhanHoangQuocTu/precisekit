**Local candidate đã qua các gate đã liệt kê; chưa đạt Definition of Done phát hành.**
Các blocker/việc bên ngoài còn lại:

1. Push/commit/tag/release cần chủ repository phê duyệt. Chưa có commit mới để báo SHA.
2. Ruleset `master-protection` đang active, yêu cầu PR + 1 approval nhưng danh sách
   required status checks rỗng. Maintainer cần chọn các CI/CodeQL contexts thực tế;
   không bypass ruleset hoặc tự đổi policy. Yêu cầu làm trực tiếp master đã được giữ.
3. Pages đang legacy master:/docs, deployment không chờ CI. Files local đã qua site
   gates; nếu muốn enforce CI trước deployment, cần đổi Pages source sang Actions
   và thêm gated deployment tương ứng. Chưa thay cấu hình từ xa. [GitHub Pages configuration](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
4. npm environment chưa có reviewer hoặc branch restrictions; cân nhắc cấu hình.
   Dependabot alerts bị tắt: maintainer bật trong Security settings nếu muốn theo dõi.
5. Cần kiểm tra Trusted Publisher, chạy CI/CodeQL/Pages trên commit mới, sau đó
   publish được phê duyệt và kiểm tra registry/provenance/validation.

## Các bước release sau phê duyệt — CHƯA chạy

Review và commit đúng file của release (tránh `git add .` gom file ngoài phạm vi),
đề xuất commit message `fix: harden parsing and release checks for 0.5.2`.
Sau commit, chạy `bash scripts/release.sh` để kiểm tra clean master và toàn bộ gates.
Tuân thủ PR/ruleset hiện tại; không force push hoặc bypass để đưa commit lên master.
Chỉ khi master trên GitHub có commit đã xác minh và CI/CodeQL mới pass, tiến hành:

```sh
git tag -a v0.5.2 -m "@fatdevcon/precisekit 0.5.2"
git push origin v0.5.2
gh release create v0.5.2 --verify-tag --title "v0.5.2" --notes-file /tmp/precisekit-v0.5.2-release-notes.md
```

Release notes file được chuẩn bị ở `plans/v0.5.2/release-notes.md`; copy sang đường
dẫn `/tmp` trong lệnh trên hoặc dùng trực tiếp file trong repository. Creating Release
kích hoạt publish thật. Kiểm tra run Publish mới success, npm 0.5.2 có provenance,
Trusted Publisher validated, năm alerts resolved và Pages deployment success.
Không suy ra kết quả những bước này từ tests local.
